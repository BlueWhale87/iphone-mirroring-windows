# Contributing research

Useful contributions include prior work on SFAuthenticationManager/Mac-unlock pairing, Rapport remote-display enrollment, AWDL transport, property-list control encoding, HID/remote-text serialization and media negotiation.

For a finding, include:

- Reference OS/app versions and build numbers.
- Artifact identity or a reproducible public source.
- Relevant procedure/address or scoped runtime observation.
- Whether the conclusion is static, observed at runtime or inferred.
- What remains unresolved and the smallest check that could settle it.

Separate a discovered API/type from a demonstrated wire requirement. A successful Mac session does not demonstrate Windows compatibility. Keep secrets and personal identifiers out of contributions; summarized/redacted observations are sufficient for discussing mechanisms.

Open an issue with a focused finding or question. The next feasibility milestone concerns independently reproducible enrollment and authenticated transport, before a full Windows application.
